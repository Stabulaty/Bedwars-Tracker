Bedwars Tracker by Stabulaty


Features:

Tracking Final Kills, Bed Destructions and Final Deaths of every party member aswell as Finals lost to other Teams.


Setup:

To start the Bedwars Tracker just click " ⁝ " and then pick the file of your latest minecraft Chat log.

Some presets if you cant figure where your current chat log is at:

Badlion Client: C:\Users\"Your Name"\AppData\Roaming\.minecraft\logs\blclient\minecraft\latest.log

Lunar Client: C:\Users\"Your Name"\.lunarclient\offline\multiver\logs\latest.log

Vanilla: C:\Users\"Your Name"\AppData\Roaming\.minecraft\logs\latest.log

The Tracker was tested on Badlion Client only so if you have issues on other clients feel free to message me.


After putting in a path for your chat log, the path will automatically be stored and accessed the next time you boot up the Tracker.

To start the Tracker ingame just type /pl or /Party list in hypixel chat


Replay Mode and custom Commands:

I tried to implement a replay mode so the Tracker wont count any stats when viewing a replay, yet it only works partially. Its almost 100% reliable if youre the Party leader, yet it can sometimes fail if you arent. In that case feel free to make use of the implemented custom commands:

Type following things in the hypixel chat to access the Tracker:

-/tracker-reset   -> Resets all stats
-/tracker-pause   -> Pauses stat detection (if you want to view a replay and make sure that no extra Finals get counted for example)
-/tracker-resume  -> Reenables stat detection


Additional Information:

-The Tracker only works if your language on hypixel is set to english
-The Tracker is only in early access yet, so message me in case you discover any Bugs
-There is no guarantee of the Tracker working on any Client besides badlion
-The Tracker can only work if a Party member is not nicked and wont Count stats of nicked players
